**Le bot copie tes traders tout seul.**

- **▶ Démarrer / ■ Stopper** fonctionnent : le bot surveille tes traders en temps réel. Chaque achat passe par SCOUT, HEAD, RISK, WHALE et SNIPER. Le JUDGE décide ensuite, avec ses 14 contrôles.
- **Compte démo** : l'argent est fictif, mais chaque ordre est chiffré avec un vrai devis Jupiter (prix, frais, impact). Les positions, les ventes et les résultats s'affichent comme en réel.
- **EXIT protège les positions** : stop-loss, prise de profit, vente quand le trader vend, durée maximale, chute de liquidité. Si tu appuies sur Stopper, il n'y a plus de nouvel achat, mais les positions restent protégées.
- **Compte réel avec Phantom** : dans Connexions, tu ajoutes un compte Phantom **dédié au bot** en collant sa clé privée. Elle est gardée dans le coffre-fort de Windows et n'est jamais affichée. Le bot signe ses ordres sur ton PC et les envoie via Jupiter. Ses trades apparaissent dans Phantom.
- Le compte réel demande une confirmation explicite. Il se désactive à la fermeture du logiciel et après un redémarrage.
- **Arrêt d'urgence** : tout s'arrête, ventes comprises, et le compte réel est désactivé.
- **En arrière-plan** : si tu fermes la fenêtre, le bot continue. Rouvre le logiciel pour retrouver l'écran.
- Nouvel encadré « Activité du bot » sur l'accueil (achats, ventes, alertes).
