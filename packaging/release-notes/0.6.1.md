**Création de la clé GMGN en un clic.**

- Menu **Connexions & test** → **Créer ma clé GMGN** : le logiciel génère sa clé de signature (Ed25519), garde la partie secrète dans le coffre-fort de Windows (Gestionnaire d'identifiants) et t'affiche la clé publique à copier sur gmgn.ai/ai (« Upload Public Key »).
- Cette clé ne donne **aucun accès** à ton wallet : elle prouve seulement à GMGN que les ordres viennent de ton logiciel.
- Champ **GMGN** dans les clés API pour coller la clé API que GMGN t'affiche ensuite.
- Barre du haut plus compacte.
